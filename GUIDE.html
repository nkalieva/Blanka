1. SUPABASE — База данных

Создать проект

  • Зайти на supabase.com → New project
  • Сохранить Project URL и anon key (Settings → API)
  • Authentication → Settings → выключить "Confirm email"

SQL — таблицы (SQL Editor → Run)

CREATE TABLE profiles (
  id UUID REFERENCES auth.users PRIMARY KEY,
  full_name TEXT,
  role TEXT CHECK (role IN ('worker', 'manager'))
);

CREATE TABLE shifts (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  worker_id UUID REFERENCES profiles(id),
  location TEXT,
  status TEXT DEFAULT 'upcoming',
  scheduled_start TIMESTAMPTZ,
  checked_in_at TIMESTAMPTZ,
  checked_out_at TIMESTAMPTZ,
  photo_url TEXT,
  voice_url TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE shifts ENABLE ROW LEVEL SECURITY;

SQL — политики доступа (RLS)

-- Профили
CREATE POLICY "Users manage own profile" ON profiles
  FOR ALL USING (auth.uid() = id);

CREATE POLICY "Authenticated users can view all profiles" ON profiles
  FOR SELECT TO authenticated USING (true);

-- Смены: worker
CREATE POLICY "Workers see own shifts" ON shifts
  FOR SELECT USING (auth.uid() = worker_id);

CREATE POLICY "Workers can insert own shifts" ON shifts
  FOR INSERT WITH CHECK (auth.uid() = worker_id);

CREATE POLICY "Workers can update own shifts" ON shifts
  FOR UPDATE TO authenticated
  USING (auth.uid() = worker_id)
  WITH CHECK (auth.uid() = worker_id);

-- Смены: manager видит всех
CREATE POLICY "Managers can view all shifts" ON shifts
  FOR SELECT USING (
    EXISTS (SELECT 1 FROM profiles
      WHERE profiles.id = auth.uid() AND profiles.role = 'manager')
  );

SQL — Storage для фото и голоса

INSERT INTO storage.buckets (id, name, public)
VALUES ('shift-photos', 'shift-photos', true) ON CONFLICT DO NOTHING;

CREATE POLICY "Authenticated users can upload photos"
  ON storage.objects FOR INSERT TO authenticated
  WITH CHECK (bucket_id = 'shift-photos');

CREATE POLICY "Anyone can view photos"
  ON storage.objects FOR SELECT TO authenticated
  USING (bucket_id = 'shift-photos');

2. GITHUB — Репозиторий через SSH

Создать SSH ключ

ssh-keygen -t ed25519 -C "email@example.com"
cat ~/.ssh/id_ed25519.pub | pbcopy

→ GitHub → Settings → SSH keys → New SSH key → вставить

ssh -T git@github.com
# Hi username! — значит работает

Подключить репозиторий

Создать репо на GitHub, потом в терминале:

git init
git remote add origin git@github.com:username/repo.git
git add -A
git commit -m "Initial commit"
git push -u origin main

3. NEXT.JS — Создать проект

npx create-next-app@latest blanka --typescript --tailwind --app
cd blanka
npm install @supabase/supabase-js @supabase/ssr
npx shadcn@latest init

Файл .env.local (создать в корне проекта)

NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGci...
echo ".env.local" >> .gitignore

lib/supabase/client.ts

import { createBrowserClient } from '@supabase/ssr'
export function createClient() {
  return createBrowserClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
  )
}

6. CI/CD — GitHub Actions

# .github/workflows/ci.yml
name: CI
on:
  push:
    branches: [main]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
      - run: npm ci
      - run: npm test
      - run: npm run build
        env:
          NEXT_PUBLIC_SUPABASE_URL: ${{ secrets.NEXT_PUBLIC_SUPABASE_URL }}
          NEXT_PUBLIC_SUPABASE_ANON_KEY: ${{ secrets.NEXT_PUBLIC_SUPABASE_ANON_KEY }}

GitHub → репозиторий → Settings → Secrets and variables → Actions → New repository secret

  • NEXT_PUBLIC_SUPABASE_URL = твой URL
  • NEXT_PUBLIC_SUPABASE_ANON_KEY = твой ключ

После каждого git push → вкладка Actions покажет ✓ или ✗

7. ЧАСТЫЕ ОШИБКИ

Ошибка Решение
new row violates RLS Выключить "Confirm email" в Supabase → Auth → Settings
Bucket not found Создать bucket в Supabase → Storage → New bucket (public: ON)
column does not exist Запустить: ALTER TABLE shifts ADD COLUMN IF NOT EXISTS photo_url TEXT;
permission denied publickey Перекопировать SSH ключ через cat ~/.ssh/id_ed25519.pub | pbcopy
ts-node required Переименовать jest.config.ts → jest.config.js
User already registered Удалить юзера в Supabase → Authentication → Users
